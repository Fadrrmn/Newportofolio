Tentang Saya

Halo! Saya Fadhlurrahman Naufal Nugraha, mahasiswa Teknologi Rekayasa Komputer di Politeknik Caltex Riau. Saya memiliki ketertarikan di bidang pengembangan aplikasi, web development, jaringan komputer, IoT, dan cybersecurity. Selama perkuliahan, saya telah mengerjakan berbagai project, mulai dari membangun aplikasi berbasis web dan Android, mengembangkan sistem IoT menggunakan ESP32, hingga melakukan konfigurasi dan simulasi jaringan komputer.

Saya adalah seseorang yang senang mencoba hal baru, belajar melalui praktik, dan memecahkan masalah secara bertahap. Saya menyadari bahwa masih banyak hal yang perlu saya pelajari, sehingga saya terus berusaha meningkatkan kemampuan teknis maupun kemampuan bekerja dalam tim. Tujuan saya adalah terus berkembang sebagai seorang IT enthusiast dan membangun pengalaman melalui berbagai project yang dapat memberikan manfaat serta menjadi bagian dari perjalanan karier saya di bidang teknologi.
